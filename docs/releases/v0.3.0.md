Добавлена **шейдерная отрисовка северного сияния на GPU**: процедурные световые ленты со складками, тонкие вертикальные лучи и зелёно-бирюзовые переливы с фиолетовым верхним свечением.

Чтобы попробовать, выберите **«Анимация → Северное сияние»**, затем **«Отрисовка северного сияния → Шейдерная (GPU)»** и нажмите **«Показать анимацию»**. Прежний вариант доступен как **«Классическая»**. Кнопка **«Сохранить и свернуть»** сохраняет выбранный способ для следующих запусков по расписанию.

Новый режим использует HLSL Pixel Shader 3.0 через WPF. При недоступности аппаратной поддержки в текущем Windows-сеансе приложение возвращается к классическому сиянию и показывает пояснение в настройках. Классическая отрисовка остаётся вариантом по умолчанию; настройки предыдущих версий сохраняются.

Проверены Release-сборка без предупреждений, сохранение настроек, возврат к программной отрисовке, переключение обоих режимов и воспроизведение в настоящем прозрачном окне. Встроенный байткод шейдера выполнен на GPU при нескольких размерах, включая 4K; проверены изменение кадров, корректная прозрачность и плавное затухание нижнего края.

Скачайте `OledAurora.exe` или архив `OledAurora-win-x64.zip`. Завершите предыдущую версию через меню трея → **«Выход»**, замените файл и запустите новую. Устанавливать .NET отдельно не нужно. Контрольные суммы находятся в `SHA256SUMS.txt`.
