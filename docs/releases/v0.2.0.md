Добавлена анимация **«Северное сияние»**: плавно движущиеся зелёные, бирюзовые и приглушённые фиолетовые световые занавесы. Выбор доступен в поле **«Анимация»** в настройках.

Исправлена резкая нижняя граница всех эффектов. Затухание теперь привязано к выбранной высоте окна, а перед нижним краем остаётся полностью прозрачный запас. Изменение высоты 5–40% масштабирует эффект и его затухание вместе.

Выбранная анимация и настройки версии 0.1.0 сохраняются при обновлении. Номер версии в окне настроек берётся из сборки.

Проверены кадры всех трёх эффектов при разных высотах и масштабах Windows, включая 4K. Проверки прозрачного края выполняются также при сборке в GitHub Actions.

Скачайте `OledAurora.exe` или архив `OledAurora-win-x64.zip`. Завершите предыдущую версию через меню трея → **«Выход»**, замените файл и запустите новую. Устанавливать .NET отдельно не нужно. Контрольные суммы находятся в `SHA256SUMS.txt`.
